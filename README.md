Equix

Equix – Invest. Learn. Grow.

A full-stack stock market dashboard for tracking stocks, managing portfolios, and simulating trades.

**Features**
User authentication
Market dashboard
Portfolio and holdings
Virtual trading
Watchlist
Transactions
Analytics
Learning resources
Virtual fund management

**Tech Stack**
Frontend: React, Vite, JavaScript
Backend: Node.js, Express.js
Database: MongoDB Atlas
Authentication: JWT
